# Changelog

## 1.1.0 - 2026-11-12

- Several wired ports: a Built-in / USB selector (`h` / `l`) picks the port that
  connect, disconnect and profile activation act on, so a laptop port and a USB
  adapter can each run their own profile at the same time.
- Profiles up on another port say which one (`on USB`).

## 1.0.0 - 2026-11-01

- Wired bar widget that shows only while a cable is plugged in.
- Live link details with click-to-copy.
- Filterable profile switcher.
- DHCP / static IPv4 editor for existing and new profiles.
- `nmtui` shortcut for advanced settings.
